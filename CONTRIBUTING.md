# Contributing to learn-css

Thank you for your interest in improving **learn-css**!

## Ways to Contribute
1. **Reporting Bugs**: Open an issue describing the problem, reproduction steps, and browser environment.
2. **Suggesting Enhancements**: Propose new topics, advanced CSS features (e.g., modern layout tricks, subgrid, container queries), or architectural improvements.
3. **Submitting Pull Requests**:
   - Fork the repository and create a feature branch (`git checkout -b feat/my-topic`).
   - Run tests: `npm test`.
   - Build project: `npm run build`.
   - Follow [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) format (`feat: ...`, `fix: ...`, `docs: ...`).
   - Open a pull request against `main`.
