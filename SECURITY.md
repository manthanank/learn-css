# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.x     | :white_check_mark: |
| 1.x     | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please send an email to **manthan.ank46@gmail.com**. All security issues will be promptly investigated and addressed. Please do not report security vulnerabilities via public GitHub issues.
