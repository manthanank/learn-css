# Changelog

All notable changes to this project will be documented in this file. See [standard-version](https://github.com/conventional-changelog/standard-version) for commit guidelines.

## [2.0.0](https://github.com/manthanank/learn-css/releases/tag/v2.0.0) (2026-09-04)

### Features
* Complete modernization of CSS curriculum covering Cascade Layers, CSS Nesting, `:has()`, Container Queries, Subgrid, and modern color spaces (`oklch`).
* Added interactive CSS showcase application with Express 5 server.
* Added CSS Specificity Calculator, Color Model Validator, and Unit Parser with 100% Vitest test coverage.
* Added multi-agent and IDE guidelines (`AGENTS.md`, `.claude/`, `.cursor/`, `.gemini/`, `.github/copilot-instructions.md`, `.junie/`, `.windsurf/`).
* Hardened CI/CD workflows with resilient step-level credential validation for DockerHub publishing and releases.
