# Gemini Guidelines: learn-css

- Architecture: Modern CSS3 Living Standard, Express 5 server, TypeScript 5.7+ backend, Vitest testing.
- Conventions: Cascade Layers (`@layer reset, base, components, utilities;`), CSS nesting, `:has()`, Container Queries, OKLCH color palettes, fluid typography (`clamp()`).
- Always run `npm test` and `npm run build` to verify correctness.
